Support

Help for the DishNab app. These answers are not for Pawprint Log.

Contact

No support email is published on this page. Use the questions below for share, paste, review, restore, backup, the grocery list, To file, on-device storage, and iCloud.

Share a link

From TikTok, Instagram, or Facebook, use the system share sheet and choose DishNab. The link needs to be a public post. Private posts, removed posts, and login-only pages can fail, and nothing is saved when an import fails. DishNab is not those apps. Their outages are outside DishNab.

Paste a link

You can paste a public link in the app. The same limits as sharing apply. A link that is not a public TikTok, Instagram, or Facebook post is not fetched by the import proxy, so paste may not produce a recipe.

Review what was imported

After a share or paste, read the title, ingredients, and steps before you cook. The source page may have left them out or the import may have kept only part of the caption. Fixing or discarding a bad import is up to you. Cooking mode does not fill missing steps and does not check allergies or nutrition.

Restore a purchase

Open Settings in DishNab and use Restore while signed in to the Apple ID that paid. Restore uses Apple’s StoreKit 2 records for that Apple ID. DishNab does not use RevenueCat. This page does not list a price. If you need a refund, ask Apple at reportaproblem.apple.com. Restore does not bring back recipes, the grocery list, or To file. What you still have is what is on the phone, plus any JSON backup you kept.

Back up and import

JSON export and import are free. In Settings, export a backup. The file can include your recipes and personal notes. You choose the destination, such as Files, Mail, or AirDrop. DishNab does not receive the file. Anyone you send it to can read it.

Import reads a JSON file you select. This page does not promise that import will merge with recipes already on the phone. Export the current library first if you want a spare copy before you import an older file.

Grocery list

The grocery list is free. It is a checklist of ingredients on this phone, kept in simple aisle groups. It stays on the device and works offline. Items you check off remain on the phone until you change them. This version does not sync the list through iCloud or to a DishNab server. It does not shop for you, and it does not check allergies.

To file

To file is the inbox for imports you have not organized yet. New imports can wait there until you file them. It is stored on this phone. It is not a shared inbox, and it does not show up on another device in this version.

On this device

Search looks through recipes stored on the phone. It does not search the web. Folders organize that same library. Cooking mode shows a recipe you already saved. Onboarding introduces these steps and does not create a DishNab account.

Recipes, the grocery list, and To file live on the device. Deleting the app, or losing the phone without a backup you kept, can delete them. There is no DishNab server copy of the grocery list or inbox to restore from.

iCloud

iCloud sync is not available. The production CloudKit schema is not deployed, so a recipe, grocery list, or To file inbox does not appear on a second device by itself. Signing in to iCloud for other apps does not copy them across phones. When you change phones, move a JSON backup yourself and import it. This page does not promise that the backup file includes the grocery list or To file.
