Support

Help for the DishNab app.

Email nouranbull@gmail.com.

Share a link

You can share a recipe link into DishNab. For a normal recipe page, the phone fetches the page and then reads it on the device. A supported social link, such as a public TikTok, Instagram, or Facebook post, is requested through DishNab’s proxy. A private or removed post may not import. DishNab is not those other apps.

Paste a link

You can paste a recipe link. A normal recipe page is fetched and then read on the phone. A supported social link uses the proxy. Either path can fail or come back incomplete.

Review an import

Before you cook, read the title, ingredients, and steps. The page you imported from may have been incomplete. Cooking mode shows the saved recipe. It does not fill missing steps or check allergies.

Restore a purchase

Search, folders, cooking mode, the grocery list, To file, and backup are free. More than 10 social imports in a month is an optional one-time purchase from Apple. There is no trial. Apple shows the price. Restore that purchase from Settings with the same Apple ID you used to buy it. Refunds are requested from Apple at reportaproblem.apple.com.

Backup and import

Export and import are free. The JSON file is written on your device, and you choose where it goes. DishNab does not receive it.

It includes recipes (ingredients, steps, the original caption, notes, source links, times, and ids), an optional photo, folders (name, order, and when created), and whether a recipe is in To file.

The grocery list is not backed up and is not exported. The file also leaves out import jobs, the social-import count, a Pro purchase, and the onboarding flag.

Import checks the file before it adds anything. It does not delete or overwrite recipes you already have. It skips a recipe with the same id or the same canonical link, and it leaves duplicates already in your library unchanged.

Grocery list

The grocery list is free. It is a checklist of ingredients on this phone, in simple aisle groups, and it works offline. Items stay until you change them. It is not included in backup or export. Grocery sync is not confirmed, and this page does not say the list will sync later. The list does not check allergies.

To file

To file is free. It is the inbox for imports you still need to organize. A JSON backup includes whether a recipe is in To file. It does not include the grocery list.

On this device

Search looks through recipes on the phone, not the whole web. Folders organize that library. Cooking mode shows a recipe you saved.

If you delete the app, recipes that exist only on that phone can go with it. Export a backup when you want a file you can import later.

iCloud

The app tries to keep recipes in your private iCloud store. If it cannot, recipes stay on the phone. If that also fails, they are held only in memory and the app shows: “Recipes will not be kept after you leave the app.”

Signing in to iCloud does not mean sync worked. Recipe sync is not confirmed on this build yet. The grocery list is stored on the phone, and grocery sync is not confirmed. A JSON backup can move recipes and folders to another phone. It will not move the grocery list.
