Privacy

These pages are for the DishNab app. They are not the Pawprint Log policy.

Recipes

The app tries to keep recipes in your private iCloud store. If that store is not available, it keeps them on the phone. If the phone store is not available either, it keeps them in memory for this visit only and shows this warning: “Recipes will not be kept after you leave the app.”

Signing in to iCloud does not mean your recipes synced. Recipe sync is not confirmed on this build. It still has to be tested on an actual build. This page does not say that sync will start later on its own.

If you use Apple’s iCloud Backup for the whole phone, that is Apple’s service. See Apple’s privacy policy.

Grocery list and the import count

The grocery list is free. It stays on the phone as a checklist of ingredients in simple aisle groups. Grocery sync is not confirmed, and this page does not say the list will sync later.

The count for the monthly social-import limit is stored on the phone and is also copied to your iCloud. Not every DishNab value stays only on the device.

Imports

For a normal recipe page on the web, the phone fetches the page from that site and then reads the recipe on the device.

For a supported social link, such as a public TikTok, Instagram, or Facebook post, the app sends the link to a DishNab proxy on Cloudflare. The proxy also receives a random install id, the app version, and whether a page fallback is allowed. That install id is not your Apple ID. The proxy requests the public post from that site. DishNab is not those sites. An import can fail or come back incomplete.

Proxy logs

The proxy writes an operational log with the route, status, time taken, platform, source, and error. Until that run of the proxy ends, it also holds the connection’s IP address and the install id in memory to apply limits.

The host’s operational logging may keep records. Logging is enabled, including a sample of traces. What those records contain was not inspected. This page does not say that every log is discarded, and it does not state how long records are kept or whether they include request bodies or headers. Cloudflare describes its own processing in the Cloudflare privacy policy.

Backup file

Export writes a JSON file on your device. You choose where it goes, such as Files, Mail, or AirDrop. DishNab does not receive it. Anyone you share it with can read it.

The file includes your recipes, with ingredients, steps, the original caption, notes, source links, times, and ids. It can include an optional photo. It includes your folders, with their names, order, and when they were created, and whether a recipe is in To file.

It does not include grocery items, import jobs, the social-import count, a Pro purchase, or the onboarding flag.

Import checks the file before it adds anything. It does not delete or overwrite recipes you already have. It skips a recipe with the same id or the same canonical link, and it leaves duplicates already in your library unchanged.

Purchases

Search, folders, cooking mode, the grocery list, To file, and backup are free. More than 10 social imports in a month uses an optional one-time upgrade from Apple. There is no trial. Apple shows the price and handles payment. DishNab does not receive your card number or other payment numbers. Apple’s side of the purchase is covered by Apple’s privacy policy.

Analytics

The app does not include an analytics SDK. Counts it keeps for parsing stay on the phone. Signals for analytics are discarded and are not sent to an analytics service. A social import that uses the proxy is still processed by Cloudflare, as described above.
