Privacy

These pages are for the DishNab app. They are not the Pawprint Log policy.

Recipes you save stay in the app on your device. A recipe page on the web, such as a blog, is read on the phone. A public post on a social site the import proxy supports can be sent to a DishNab proxy on Cloudflare, which then requests that page from the site. That request is not a second cookbook stored by DishNab.

On your device

Recipes, notes, folders, search, and cooking mode are kept on your phone. The grocery list is free. It is an offline checklist of ingredients, stored on the phone, with simple aisle groups. To file is the inbox for imports you have not organized yet, and it is stored on the phone.

iCloud sync may be unavailable during testing. Until a library shows up on a second device, the phone you are using is the copy you have. Deleting the app can remove what is only on that phone.

iCloud

Sync through iCloud may be unavailable while the app is tested. A recipe, grocery list, or To file inbox may not appear on another device during that time.

If you use Apple’s iCloud Backup for the whole phone, that is Apple’s service. See Apple’s privacy policy.

Imports

Pasting or sharing a normal recipe page, such as a blog, uses on-device parsing.

Pasting or sharing a public post on a social site the proxy supports sends that link to the DishNab proxy on Cloudflare. The proxy requests the public page from that site. Public posts on sites such as TikTok, Instagram, and Facebook are the kind of link this proxy is for. DishNab is not those sites, and a private or removed post may not import.

An import can fail or come back with only part of the recipe. Read the result before you rely on it.

Cloudflare

When a link is sent to the proxy, Cloudflare processes the request in order to answer it. That processing includes the connection’s IP address and ordinary request metadata, and the public page the proxy requests. This is host processing, not a DishNab copy of your recipes. Cloudflare describes its own processing in the Cloudflare privacy policy.

Backup file

You can export a JSON backup on your device and import a JSON file you choose. The file goes only where you send it, such as Files, Mail, or AirDrop. DishNab does not receive it. Anyone you share it with can read what is inside.

Purchases

If you buy an optional upgrade, Apple handles the payment. DishNab does not receive your card number or other payment numbers. Apple’s side of the purchase is covered by Apple’s privacy policy.

Analytics

Analytics is not part of this app. A social import that uses the proxy is still processed by Cloudflare, as described above.
