Privacy

These pages are for the DishNab app. They are not the Pawprint Log policy.

Your recipes stay in the app on your device. An import is different: a public link, and sometimes recipe text, is processed by a DishNab proxy on Cloudflare and by the site the link points to. That processing is not a second copy of your cookbook stored by DishNab.

Recipes on your device

Recipes, notes, folders, search, cooking mode, the grocery list, and the To file inbox are stored on your phone. The grocery list is a free offline checklist of ingredients with simple aisle groups. To file holds imports until you organize them. Neither is stored as a DishNab cloud list, and this version does not sync them. This version does not ask you to create a DishNab account. If you delete the app, what is on that phone can go with it. A JSON backup is a file you keep yourself.

iCloud

A private iCloud sync path (CloudKit) is intended for a later version. The production CloudKit schema is not deployed. This version does not sync recipes, the grocery list, or To file through iCloud. Saving something on one device does not make it appear on another because of iCloud.

If you use Apple’s own iCloud Backup for the whole phone, that backup belongs to your Apple account and follows Apple’s privacy policy. It is not DishNab sync, and this page does not promise that Apple’s phone backup contains a restorable DishNab library.

Imports

When you share or paste a public TikTok, Instagram, or Facebook link, the app sends that URL to the DishNab proxy on Cloudflare. It also sends an install id, the app version, and whether a page-caption fallback is allowed. The install id is a rate-limit key. It is not your Apple ID and it is not a DishNab account.

The proxy then requests the public page, or that site’s public embed data, from the upstream site. Page text is read in that request so a caption can be returned to the app, along with a creator name and a thumbnail link when the page provides them. Loading a thumbnail contacts the site that hosts the image.

If the app sends recipe text to the proxy to be parsed, the proxy receives that text. The current proxy does not call a cloud AI model. It applies a limit and answers that AI is unavailable. The text is not written into a DishNab recipe database.

The proxy does not keep your recipes. It does keep short-lived rate-limit counts in memory, keyed by the install id and by the connection’s IP address. Those counts are discarded as the proxy runs; they are not your library.

A private, removed, or blocked post can fail. The proxy accepts public TikTok, Instagram, and Facebook links. It does not fetch other websites. DishNab is not those sites.

Logs and Cloudflare

For each proxy request, the app log records the route, the status, how long it took, the platform, a source label, and an error code. That log line does not include the recipe URL or the recipe text.

Cloudflare still processes the request in order to run the proxy. The URL or text is in that request while it is handled. This is transient processing by the host, not a DishNab cookbook. Workers Observability is enabled for the proxy: invocation logs are persisted, and a sample of traces is persisted. Cloudflare can also keep its own hosting logs. Those records are operational. They are not “no data was processed.” Cloudflare describes its own processing in the Cloudflare privacy policy.

Backup file

Export writes a JSON file on your device. The file can contain your recipes, personal notes, and the other recipe fields the app saved. Import reads a JSON file you choose. The file goes only where you send it, such as Files, Mail, or AirDrop. DishNab does not receive it. Anyone you share it with can read what is inside.

Purchases

If you buy an optional upgrade, Apple handles the payment with StoreKit 2. DishNab does not use RevenueCat and does not receive your card number. The price is whatever Apple shows you before you pay. Apple’s payment records are covered by Apple’s privacy policy.

Tracking

This version does not include an analytics or tracking product, and it does not show ads. The import processing and operational logs above still happen. This page does not say that DishNab collects nothing.
